Fonctionnalités principales :

  • Installation et configuration de Windows Server 2019
  • Création de l'annuaire Active Directory (medoclab.local)
  • Gestion des Unités Organisationnelles (UO) et groupes
  • Mise en place des stratégies de groupe (GPO)
  • Création de répertoires partagés avec permissions
  • Scripts d'automatisation PowerShell
  • Configuration des restrictions horaires d'accès

Technologies utilisées :

Windows Server 2019 Active Directory PowerShell GPO DNS DHCP Partages réseau

  • Structure AD : medoclab.local avec UO pour chaque département

Services configurés :
